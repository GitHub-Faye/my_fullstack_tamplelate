# ADR-0002: 星点规则采用固定比例阈值

完成判定采用固定比例阈值（如 T实 <= 0.8 × T报 判定为"提前完成"），而非动态算法。

**理由**：
- 规则透明可预期，工程师能理解计算逻辑
- 便于管理员在规则配置中调整阈值
- 避免复杂算法带来的争议和维护成本

**规则表**（可配置）：
| 判定 | 条件 | 星点变化 |
|------|------|----------|
| 提前完成 | T实 ≤ 0.8 × T报 | +5 |
| 按时完成 | T实 ≤ T报 | +3 |
| 超时 ≤ 20% | T实 ≤ 1.2 × T报 | -5 |
| 超时 21-50% | T实 ≤ 1.5 × T报 | -10 |
| 超时 51-100% | T实 ≤ 2 × T报 | -20 |
| 超时 > 100% | T实 > 2 × T报 | -30 |
