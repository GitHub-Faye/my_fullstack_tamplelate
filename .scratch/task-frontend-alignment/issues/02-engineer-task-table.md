# 02 — 工程师端任务列表对齐原型

**What to build:** 工程师在 `/engineer` 页面看到与原型一致的任务管理体验：

**"我的任务"标签页：**
- 表格 8 列：任务、类型、T报、T实、T报完成时间、当前阶段/进度、状态、操作
- 待启动(pending_start) 状态 → "启动"和"拒绝"按钮（已有）
- 进行中(in_progress) 状态 → 新增"申请暂停/顺延"按钮（当前缺失）
- 暂停中(paused) 状态 → 新增"恢复"按钮（当前缺失）
- 已完成(completed) 状态 → "详情"按钮（只显示详情）
- 竞价中(bidding) 状态 → "报价"按钮（在竞价标签页处理）

**"竞价任务"标签页：**
- 表格 7 列：任务、类型、发布人、预期上线、报价倒计时、状态、操作
- 列顺序与原型一致
- 报价弹窗增加 H0 和报价金额计算展示
