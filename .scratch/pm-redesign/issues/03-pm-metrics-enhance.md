# 03 — 前端：PM 指标卡增强（环比数据 + 分状态计数 + 收入试算明细）

**What to build:** 增强 PMWorkspacePage 的 4 个指标卡，展示从扩展后的 PMDashboard 获取的环比数据、分状态任务计数，以及「收入试算」的查看明细功能。

**Blocked by:** #01 — 后端扩展 PMDashboard

**Status:** ready-for-agent

### 包含内容

**指标卡 1：本月新增客资**
- 主数值：本月新增数
- 环比描述："上月新增客资 X"

**指标卡 2：今日新增客资**
- 主数值：今日新增数
- 环比描述："昨日新增客资 X"

**指标卡 3：我发布的任务**
- 主数值：总数
- 分状态描述："竞价中 X / 进行中 X / 未确定 X / 已完成 X"

**指标卡 4：收入试算**
- 主数值：¥X,XXX
- 描述文本："本月预估收入"
- 「查看明细」链接 → 点击弹出 Dialog，展示工资计算明细（暂时用占位数据）
