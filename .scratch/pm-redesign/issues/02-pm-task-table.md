# 02 — 前端：重构 PMTaskTable 独立组件（含详情弹窗）

**What to build:** 创建 PM 专属的 `PMTaskTable` 组件，替代当前共享的 `TaskTable`。实现完整的筛选栏（发布人/类型/状态）、操作列（按角色+任务状态动态显示按钮）、以及「详情」弹窗（展示任务信息 + 附件表格占位 + 工作日志 + 动态操作按钮）。

**Blocked by:** #01 — 后端扩展 PMDashboard（如果是分状态计数或环比数据直接展示在表格内则无阻塞，但指标卡增强需要）

**Status:** ready-for-agent

### 包含内容

**1. PMTaskTable 组件**
- 筛选栏：发布人（全部/我发布的/其他PM）+ 任务类型 + 任务状态 + 搜索/重置按钮
- 表格列：任务、发布人、类型、工程师、预期上线、T报完成时间、当前阶段/进度、状态、操作
- 操作列按 PRD 中 PM 角色的状态映射：
  - 未确认 → 编辑 / 删除
  - 竞价中 → 编辑 / 报价记录 / 撤回
  - 待启动 → 查看日志
  - 进行中 → 资料变更 / 查看工作日志
  - 暂停中 → 查看暂停记录
  - 已完成 → 查看归档日志
- 分页

**2. 详情弹窗（Dialog）**
- 不跳转路由，在 TaskTable 所在页直接弹 Dialog
- 展示：任务名称、类型、发布人、发布时间、预期上线、T报、T报完成时间、资料完整度、任务说明
- 已启动的任务额外显示：执行工程师、当前进度、T实
- 附件表格（留空占位，表头：文件、类型、状态、操作）
- 工作日志区域（暂时留空占位，表头：日期、投入、阶段/进度、说明）
- 底部操作按钮（与表格操作列状态一致）

**3. 修改链接**
- `apps/web/app/(dashboard)/pm/page.tsx` — 将 `TaskTable` 替换为 `PMTaskTable`
- 从 `features/task/client/index.ts` 中删除 `TaskTable` 的导出引用（如果不再被其他角色使用）
- 保留 `TaskTable` 组件源文件（可能其他角色暂未引用，等确认后删除）

- [ ] 操作列按钮根据任务状态动态显示（PM 视角）
- [ ] 点击「详情」弹出 Dialog 展示完整信息
